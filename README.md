# Spotify Downloader (GitHub Actions)

Personal educational tool to download a Spotify track as MP3 via GitHub Actions.

**WARNING:** This uses an unofficial API and violates Spotify's ToS. Only for personal/educational use.

## How to use

1. Go to the **Actions** tab of your repo.
2. Select the **"Download Spotify Track"** workflow.
3. Click **"Run workflow"**.
4. Paste a Spotify track URL like `https://open.spotify.com/track/4cOdK2wGLETKBW3PvgPWqT`
5. Click **Run workflow**.

The downloaded MP3 will appear in the `downloads/` folder.
